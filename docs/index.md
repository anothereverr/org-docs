# Documentation Portal

Welcome to the organization's central documentation portal.

This portal aggregates the wikis from all repositories in the organization into a single, searchable interface. Content is synchronized automatically every 30 minutes.

## How to find documentation

Use the **navigation sidebar** on the left to browse repositories, or use the **search bar** at the top to find content across all wikis.

## Contributing

Documentation lives in each repository's wiki. To update a page:

1. Navigate to the relevant repository on GitHub
2. Click the **Wiki** tab
3. Edit the page directly

Changes will be reflected here within 30 minutes.
